# קליית בראשית – ניהול מנויים

המערכת מציגה רק את ניהול המנויים של שני הסניפים:
- ביתר עילית A
- ביתר עילית B

בכל סניף ארבעה עובדים קבועים. מנהל סניף רואה ומעדכן רק את הסניף שלו. מנהל האזור יכול לעבור בין שני הסניפים ולהגדיר את סיסמאותיהם.

## אחסון קבלות
צילומי הקבלות מוקטנים לדימוי JPEG של עד כ־850KB ונשמרים בטבלת `employee_subscriptions` במסד D1 הקיים. אין צורך ב־R2 או בהפעלת מנוי אחסון נוסף. כל קבלה זמינה רק למשתמש מורשה של הסניף או למנהל האזור.

## עדכון מסד הנתונים
לפני הפעלת גרסת המסך החדשה, במסד D1 בשם `coffee-champions-db`:
1. פתח את D1 Console.
2. הרץ את תוכן הקובץ `migrations/0005_simple_subscriptions.sql`.
3. הפעולה יוצרת טבלת מנויים חדשה ומנקה את דיווחי המנויים הישנים מטבלת `reports`. טבלאות המשתמשים וההתחברויות (`users`, `sessions`) אינן נמחקות.

לאחר הרצת ה-SQL יש לפרוס את גרסת האתר החדשה מ-`main`.

## חשבונות
- משתמש סניף: שם המשתמש הוא שם הסניף המדויק, והסיסמה מוגדרת על ידי מנהל האזור.
- מנהל אזור: משתמש קיים נשמר ללא שינוי. משתמש מנהל האזור יכול להגדיר סיסמה לכל אחד משני הסניפים במסך.
- אם צריך להגדיר מנהל אזור בפעם הראשונה, אפשר להשתמש בתהליך האתחול הקיים דרך `BOOTSTRAP_SECRET` ב-Cloudflare. לאחר האתחול יש להסיר את הסוד מההגדרות.

## אבטחה ומגבלות
- השרת קובע את הסניף לפי ההתחברות, ולא סומך על שם הסניף שנשלח מהדפדפן של מנהל סניף.
- שמות העובדים מוגבלים לרשימה קבועה בקוד השרת.
- קבלות נמסרות רק אחרי בדיקת session והרשאת סניף.
- התמונות עוברות דחיסה בדפדפן כדי להישאר מתחת למגבלת גודל השורה של D1.
