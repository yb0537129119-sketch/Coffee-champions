# COFFEE CHAMPIONS – גרסת ענן פשוטה

- מנהל סניף: שם משתמש וסיסמה זהים לשם הסניף.
- מנהל אזור: שם משתמש **מנהל אזור**, סיסמה **b12345**.
- מנהל סניף מזין שם עובד ומספר מנויים בלבד.
- מנהל אזור משנה יעדים; אחוזי הביצוע והדירוג מחושבים אוטומטית.
- הנתונים משותפים בין מכשירים באמצעות Cloudflare D1.

## הגדרה ב-Cloudflare Pages
1. חבר את המאגר הזה לפרויקט Pages דרך Settings / Builds & deployments / Connect to Git.
2. במסד D1 הקיים בשם **coffee-champions-db**, פתח Settings / Bindings או בפרויקט Pages: Settings > Functions > D1 database bindings.
3. הוסף binding בשם `COFFEE_DB` ובחר את `coffee-champions-db`.
4. בצע Deploy מחדש.
5. בדוק את האתר ודווח מסניף אחד; רענן ממכשיר נוסף כדי לוודא שהדיווח מופיע.

הטבלאות `reports` ו-`targets` כבר נוצרו במסד הנתונים לפי הוראותיך; אין צורך להריץ שוב את קובץ ה-migration.

## פרטי התחברות
- כל סניף: שם הסניף בתור שם משתמש וסיסמה.
- מנהל אזור: `מנהל אזור` / `b12345`.
